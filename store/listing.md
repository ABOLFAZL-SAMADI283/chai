
## ۳) توضیح کامل (حداکثر ۴۰۰۰ کاراکتر)

```
☕ چای — اپ تمرکز با طعم چای

هر بار که می‌خواهی جدی کار کنی، یک فنجان چای بریز. تا وقتی چای داغ است، حواس‌پرتی ممنوع.

«چای» یک اپ تمرکز ساده و خوش‌ساخت است: هدف و مدت تمرکزت را انتخاب می‌کنی، چای بریزی، و در طول جلسه اپ‌های حواس‌پرت‌کن مثل تلگرام، اینستاگرام و یوتیوب قفل می‌شوند. تمام!

▸ چطور کار می‌کند؟
• هدف تمرکزت را انتخاب کن: درس خواندن، کتاب، کار کردن، یا هدف خودت
• مدت جلسه را تعیین کن: از ۱۵ دقیقه تا چند ساعت
• «بریز چای» را بزن — ماگ چای آرام‌آرام پر می‌شود و زمان شروع می‌کند
• در طول جلسه، تلگرام و بقیه اپ‌های مزاحم قفل می‌شوند
• در پایان، چای تمام می‌شود، قفل باز می‌شود و وقت تمرکزت ثبت می‌شود

▸ ویژگی‌ها
✔ قفل واقعی اپ‌های حواس‌پرت‌کن با دسترسی Accessibility
✔ انتخاب دلخواه اپ‌هایی که می‌خواهی قفل شوند
✔ داشبورد آمار: نمودار هفتگی، نقشهٔ حرارتی ۵ هفته، مجموع تمرکز روزانه
✔ لیگ هفتگی: با بقیه رقابت کن، بالا برو یا از لیگ پایین بیفت
✔ چالش دوئل با دوستت و چالش روزانه
✔ نشان‌ها و عنوان‌های مختلف برای کسانی که پیوسته تمرکز می‌کنند
✔ «همین الان N نفر مثل تو در حال تمرکز هستند»
✔ نمای تاریک و روشن
✔ حساب کاربری بدون رمز: فقط یک نام کاربری و یک کد بازیابی
✔ رابط کاربری کاملاً فارسی و راست‌به‌چپ
✔ انیمیشن‌های نرم و لذت‌بخش در تمام صفحه‌ها

▸ چرا «چای»؟
اکثر اپ‌های تمرکز خشک و بی‌روح‌اند. «چای» با یک ماگ چای که در طول جلسه پر می‌شود، حس می‌دهد که داری واقعاً یک فنجان چای می‌نوشی و آرام و با حوصله کار می‌کنی.

▸ مناسب برای
• دانشجوها و کنکوری‌ها
• برنامه‌نویس‌ها و کسانی که کد می‌زنند
• کارمندهایی که تمرکز عمیق لازم دارند
• هر کسی که می‌خواهد گوشی را کنار بگذارد و کارش را تمام کند

▸ دسترسی‌های ویژه
اپ برای قفل کردن اپ‌های حواس‌پرت‌کن از سرویس Accessibility استفاده می‌کند. این دسترسی فقط هنگام جلسهٔ تمرکز فعال می‌شود و بعد از پایان آن غیرفعال می‌شود. هیچ محتوایی از صفحهٔ شما خوانده یا ذخیره نمی‌شود. دسترسی Usage Access فقط برای محاسبهٔ زمان واقعی استفاده از اپ‌ها در داشبورد استفاده می‌شود.

▸ حریم خصوصی
ما پیام، مخاطب، فایل یا موقعیت مکانی شما را جمع‌آوری نمی‌کنیم. آمار تمرکز ابتدا روی خود گوشی ذخیره می‌شود و اگر حساب بسازید، برای نمایش در لیگ همگام می‌شود. برای شروع حساب کاربری به شمارهٔ تلفن یا ایمیل نیازی ندارید.

ساخته‌شده با ❤️ در تهران
```

## ۶) توضیح Accessibility برای فرم‌های پلی/مایکت

> Play Store از شما «توضیح دسترسی» (Accessibility API declaration) می‌خواهد. این متن را در فرم کپی کنید:

```
اپ با استفاده از AccessibilityService اپ‌های انتخاب‌شدهٔ حواس‌پرت‌کن را هنگام
شروع یک جلسهٔ تمرکز مسدود می‌کند و در پایان جلسه قفل را برطرف می‌کند.
هیچ محتوایی از صفحهٔ کاربر خوانده، ذخیره یا به سرور ارسال نمی‌شود.
سرویس فقط زمانی فعال است که کاربر یک جلسهٔ تمرکز را شروع کرده باشد.
```

## ۸) نکتهٔ مهم دربارهٔ امضا (برای هر دو فروشگاه)

**از همان یک کلید برای مایکت و کافه‌بازار استفاده کن.** اگر یک اپ با package name یکسان
ولی با دو امضای متفاوت در دو فروشگاه منتشر شود، فروشگاه دوم آن را رد می‌کند.
کلید فعلی (`chai` / keystore در Secrets) برای هر دو فروشگاه استفاده می‌شود و
برای به‌روزرسانی‌های بعدی هم باید همین کلید نگه داشته شود.

> ⚠️ کلید امضا (`release.jks`) هرگز نباید گم شود — بدون آن، آپلود نسخهٔ به‌روزشده ممکن نیست.
> نسخهٔ پشتیبان: در GitHub Secrets ریپو به‌صورت base64 ذخیره شده (`KEYSTORE_BASE64`).
