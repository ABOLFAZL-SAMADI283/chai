# راهنمای نصب «چای» روی گوشی و رفع خطاها

APK ریلیز: `Desktop\Chai\chai-release.apk` — حجم **۱۰.۲ مگابایت** — امضاشده با کلید اختصاصی.

> ⚠️ نکتهٔ کلیدی: خطای «Protected / برنامه محافظت‌شده» **مشکل خودِ اپ نیست**.
> اندروید ۱۴ به بعد هر اپی که از فروشگاه نصب نشده باشد را «محافظت‌شده» می‌داند و
> نصب را متوقف می‌کند. چند قدم زیر مشکل را کامل حل می‌کند.

---

## گام ۱ — اجازهٔ نصب از منبع ناشناس

```
Settings (تنظیمات)
 → Apps (برنامه‌ها)
 → Special app access (دسترسی ویژه)
 → Install unknown apps (نصب برنامه‌های ناشناس)
 → روی برنامه‌ای که فایل را از آن باز می‌کنی (Files / My Files / مرورگر) بزن
 → Allow (اجازه بده) ✅
```

## گام ۲ — خاموش کردن تأیید ویژه (اندروید ۱۴+)

این گام همان پیام «Protected / برنامه محافظت‌شده» را برطرف می‌کند:

```
Settings → Apps → Special app access → Enhanced confirmation (تأیید ویژه)
 → کلید را OFF کن ✅
```

یا اگر روی گوشی‌های سامسونگ/شیائومی گزینه را پیدا نکردی:

```
Settings → Security and privacy → More security settings → Install unknown apps
```

## گام ۳ — خاموش کردن Play Protect (موقتی)

```
Play Store → Profile → Play Protect → Settings
 → «Scan apps» را OFF کن ✅
 (بعد از نصب دوباره ON کن)
```

## گام ۴ — نصب

فایل `chai-release.apk` را باز کن → Install → اگر پنجرهٔ «Protected» آمد،
**«Install anyway / به هر حال نصب کن»** را بزن.

---

## اگر باز هم نصب نشد — تشخیص بر اساس پیام خطا

| پیام خطا | علت | راه‌حل |
|---|---|---|
| `App not installed` / «برنامه نصب نشد» | نسخهٔ قبلی با امضای دیگری روی گوشی است | نسخهٔ قبلی را حذف کن و دوباره نصب کن |
| `Protected app` / «برنامه محافظت‌شده» | تأیید ویژهٔ اندروید ۱۴+ | گام ۲ |
| `App blocked by Play Protect` | پلی‌پروتکت | گام ۳ |
| `For your security… not allowed to install unknown apps` | مجوز منبع ناشناس | گام ۱ |
| `package appears to be invalid` | فایل خراب/ناقص دانلود شده | فایل را دوباره دانلود کن (۱۰.۲ مگابایت) |
| `INSTALL_FAILED_INSUFFICIENT_STORAGE` | حافظهٔ کم | چند گیگ خالی کن |
| `package installer keeps stopping` | نصب‌کنندهٔ سیستم مشکل دارد | گوشی را ریستارت کن، دوباره تلاش کن |
| `App requires newer Android version` | اندروید خیلی قدیمی | حداقل **اندروید ۷.۰** (API 24) لازم است |

## 📌 راه‌حل همیشگی: نصب از مایکت / کافه‌بازار

اگر هر کدام از گام‌ها بالا روی گوشی تو جواب نداد، **منتشر کردن در مایکت و کافه‌بازار** مشکل را
از ریشه حل می‌کند:

- نصب از داخل اپلیکیشن فروشگاه ⇒ هیچ پیام «Protected» و «منبع ناشناس» نمی‌آید
- هر دو فروشگاه **رایگان** هستند (برخلاف گوگل‌پلی که ۲۵ دلار + کارت بانکی خارجی می‌خواهد)
- درآمدزدنی از طریق تبلیغات داخل خود فروشگاه‌ها انجام می‌شود

---

## بعد از نصب (اولین اجرا)

1. **Accessibility**: تنظیمات ← Accessibility ← «چای» ← روشن
2. **Usage access**: تنظیمات ← Apps ← Special app access ← Usage access ← «چای» ← روشن
3. یک هدف انتخاب کن → مدت → «بریز چای» ☕

> این دو دسترسی فقط برای قفل کردن اپ‌های حواس‌پرت‌کن لازم‌اند و بعد از پایان جلسه غیرفعال می‌شوند.
