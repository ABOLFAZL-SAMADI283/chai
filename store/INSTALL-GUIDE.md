## 🔧 اندروید ۱۲ (و ۱۱): خطای «Protected / برنامهٔ محافظت‌شده»

اگر اپ را **از مرورگر یا پیام‌رسان** نصب کرده باشی، اندروید ۱۱ به بعد آن را
«Protected app» می‌داند و **اجازهٔ روشن‌کردن Accessibility را نمی‌دهد**
(Accessibility هستهٔ کار اپ است، پس بدون آن اپ کار نمی‌کند).

### راه‌حل (۳۰ ثانیه)

```
Settings (تنظیمات)
 → Apps (برنامه‌ها)
 → See all apps (همهٔ برنامه‌ها)
 → چای
 → پایین صفحه: «Allow restricted settings» / «اجازهٔ تنظیمات محدود» → ON ✅
 → برگرد و Accessibility را فعال کن
```

> در فارسی ممکن است این گزینه «دسترسی‌های محدودشده» یا «برنامه‌های محافظت‌شده» نوشته شده باشد.

### راه بهتر: نصب از فایل‌منیجر (نه از مرورگر)

اگر فایل را اول **کپی کن داخل حافظهٔ گوشی** (Downloads) و بعد از برنامهٔ «Files / My Files»
باز کنی، اندروید اپ را «محافظت‌شده» نمی‌داند و دسترسی بدون دردسر روشن می‌شود.

### اگر اصلاً نصب نمی‌شود

| پیام خطا | علت | راه‌حل |
|---|---|---|
| `App not installed` | نسخهٔ قبلی با امضای دیگر | نسخهٔ قبلی را حذف کن، دوباره نصب کن |
| `Play Protect blocked this app` | سپر ایمنی گوگل | `Play Store → Profile → Play Protect → ⚙ → Scan apps` را موقتاً OFF کن |
| `not allowed to install unknown apps` | مجوز منبع ناشناس | `Settings → Apps → Special app access → Install unknown apps → (فایل‌منیجر) → Allow` |
| `package appears to be invalid` | فایل خراب/ناقص | دوباره دانلود کن (۱۰.۷ مگابایت) |
| `INSTALL_FAILED_INSUFFICIENT_STORAGE` | حافظه کم | چند گیگ خالی کن |
| `package installer keeps stopping` | نصب‌کنندهٔ سیستم | گوشی را ریستارت کن |

### اندروید ۱۴+ (اگر روزی گوشی را عوض کردی)

```
Settings → Apps → Special app access → Enhanced confirmation → OFF
```

## 🧩 بعد از نصب (اولین اجرا)

1. **Accessibility**: `Settings → Accessibility → چای` ← روشن
2. **Usage access**: `Settings → Apps → Special app access → Usage access → چای` ← روشن
3. یک هدف انتخاب کن → مدت → «بریز چای» ☕

> این دو دسترسی فقط برای قفل کردن اپ‌های حواس‌پرت‌کن لازم‌اند و بعد از پایان جلسه غیرفعال می‌شوند.
> **نسخهٔ ۱.۰.۱ و بعدتر** این دو مورد را داخل خود اپ نشان می‌دهد و دکمهٔ «روشن کن» دارد؛
> اگر بنر زرد بالای صفحهٔ خانه را دیدی، یعنی یکی از دسترسی‌ها هنوز فعال نیست.

## 📌 راه‌حل همیشگی: نصب از مایکت / کافه‌بازار

اگر هیچ‌کدام از راه‌های بالا روی گوشی تو جواب نداد، **منتشر کردن در مایکت و کافه‌بازار**
مشکل را از ریشه حل می‌کند: نصب از داخل اپ فروشگاه ⇒ نه «Protected» می‌آید، نه «منبع ناشناس»،
نه Play Protect. هر دو فروشگاه رایگان‌اند.
